# Kymera Launcher

## Introdução
O Kymera Launcher é um software leve e personalizável para gerenciar e atualizar seus jogos de forma simples e segura tendo a opção de baixar jogos repacks na aba downloads em varios sites ja disponibilizados, ou se preferir pode adicionar os seus sites favoritos.

## Requisitos
- Windows 10 ou superior
- 50MB de espaço livre

## Instalação
1. Baixe a versão mais recente na aba [Releases](https://github.com/SEU-USUARIO/Kymera-Launcher/releases)
2. Extraia o arquivo .zip em uma pasta de sua preferência
3. Execute `KymeraLauncher.exe`

## Configuração
- Coloque o `version.txt` na mesma pasta do launcher
- Para alterar o link de download, ou diretamente no código
- Personalize skins e ícones na pasta 

## Atualizações
- Verifique se o `version.txt` está atualizado
- Baixe a nova release quando disponível

## Observações
- Não altere arquivos internos do launcher sem conhecimento
- Mantenha backup de seus dados
